# Pattern

패턴분석 페이지입니다. 환율조정 BTC 김프(2017~현재)의 장기 추이를 한눈에 보여주고, 그래프 위 구간(음영 띠)이나 사건(점)을 누르면 그 시점 전후를 확대해서 자세히 보여줍니다. 순수 HTML/CSS/JS로 구현했고, 서버 없이 정적으로 서빙됩니다.

## 핵심 파일

| 파일 | 역할 |
|---|---|
| `pattern.html` | 페이지 전체(마크업+스타일+로직 인라인). 상단 장기 추이 차트(overview: 주간 평균선 + 구간 음영 + 사건 점)와, 구간/사건 클릭 시 열리는 상세 패널(확대 차트 zoom + 통계 카드 + 환율/BTC 미니 차트)로 구성 |
| `shared.js` | `getBtcPremiumData()`로 `data/history.json`을 읽어와 BTC 가격·해외 시세·환율 시계열을 공급 |

### 상단 개요 차트 (overview)

`data/history.json`의 일별 데이터를 ISO 주(월요일 시작) 단위로 평균 내 `buildWeekly()`로 주간 평균선을 그립니다. 그 위에 두 종류의 마커를 겹쳐 그립니다.

- **구간(period)**: 여러 주에 걸친 사건 — 시작~끝 날짜를 음영 띠로 표시
- **사건(event)**: 하루 만에 끝난 사건 — 점으로 표시. 환율까지 함께 흔든 사건은 별도 강조

이 구간/사건 목록(`periods`/`events` 배열)은 팀이 직접 조사해서 채운 정성적 데이터로, `pattern.html` 안에 직접 하드코딩되어 있습니다. `data/events.json`(대시보드·챗봇의 `recent_event`용, 최근 7일 이내 이벤트 한 줄 요약)과는 목적이 다른 별개의 목록이니 혼동하지 않아야 합니다.

라벨끼리 겹치지 않도록 `spreadX()`(좌우로 밀어내기)를 먼저 적용하고, 그 뒤 라벨이 다른 점·다른 구간의 띠·실제 선 높이와 겹치는 경우를 확인해 위로 밀어내는 몇 단계의 일반적인 충돌 회피 로직을 거칩니다(특정 이벤트를 하드코딩해서 예외 처리하지 않고, 어떤 라벨에나 적용되는 규칙으로 처리).

### 상세 패널 (구간/사건 클릭 시)

- **확대 차트(zoom)**: 클릭한 구간·사건 전후(사건은 약 2주, 구간은 구간 전체)를 확대해서 보여주고, 그 구간의 최저↔최고를 잇는 화살표를 애니메이션으로 그립니다. 화살표 색은 상승(`--accent`, 빨강)/하락(`--kimp-down`, 파랑)으로 방향에 따라 달라집니다.
- **통계 카드**: 1일/3일/7일 전 대비 변화량(사건) 또는 구간 내 최대 변동 구간. 급락일(장중 저점이 종가와 크게 다른 날)에는 이 대신 "당일 종가 김프 / 당일 장중 저점 / 종가↔저점 차이"를 보여줍니다.
- **환율/BTC 미니 차트**: 해당 기간 환율·BTC 가격의 변화율을 각각 보여주는 작은 라인 차트.

## 데이터 파일

| 파일 | 역할 |
|---|---|
| `data/history.json` | 2017-09-25(BTC 상장일)부터 오늘까지 전체 시계열. `update_data.py`가 매일 갱신. `btc_krw_low`(업비트 장중 저가)를 포함하고 있어, 종가만으로는 "아무 일 없던 날"처럼 보이는 급락일(예: 2024-12-03 비상계엄)도 설명할 수 있습니다 |

## 자동화

| 파일 | 역할 |
|---|---|
| `.github/workflows/update-data.yml` | 매일 자동으로 `update_data.py`를 실행해 `data/history.json`(+`data/current.json`)을 갱신하는 GitHub Actions 워크플로우. 웹에서 수동 실행(`workflow_dispatch`)도 가능 |

## 데이터 계산 방식

김프%는 `(btcPrice - foreignUsd * fxRate) / (foreignUsd * fxRate) * 100`으로 클라이언트(`pattern.html`)에서 계산합니다. `update_data.py`가 `data/history.json`에 미리 계산해 둔 `btc_premium_pct`를 그대로 쓰지 않고, 원본 필드(`btc_krw_price`/`foreignUsd`/`fx_rate`)로 프런트에서 다시 계산한다는 점이 dashboard·backend와 다릅니다.

장중 저점 김프(`lowPremium`)도 같은 공식에 종가 대신 `btcPriceLow`(값이 있는 날짜만)를 넣어 계산합니다. 저가가 없는 날은 종가 기준 김프값을 그대로 씁니다.

주간 평균선은 `buildWeekly()`가 날짜를 ISO 주(월요일 시작) 단위로 묶어, 그 주에 속한 모든 날짜의 김프%를 평균한 값입니다. 2017년부터의 장기 추이를 보여주는 그래프라 일별 노이즈를 줄이기 위한 처리입니다.
